# MODERN Art AI アドバイザー

ボードゲーム『MODERN Art』(Reiner Knizia) に特化した対話型 AI です。
場に出たカードと落札額を入力していくと、あなたの番に「どのカードを出すか」
「いくらまで競るか」を、その場で数千回シミュレーションして提案します。

非公式のファンツールです。ゲーム本体とは無関係で、権利者とは一切関係ありません。
『MODERN Art』は Reiner Knizia 氏の作品です。
計算はすべて手元のPCで行われ、外部には何も送信されません。

依存は Python 3.10+ の標準ライブラリのみ（追加インストールは不要です）。

## 使い方

**`モダンアートAI.bat` をダブルクリックするだけです。**

黒い画面が開き、数秒でブラウザに操作画面が表示されます（開かない場合は
`http://localhost:8765/` を自分で開いてください）。

- 遊んでいる間、**黒い画面は開いたままにしておいてください**。これがAIの本体です
- **終了するときは黒い画面を閉じます**

画面の流れ:

1. 人数、自分が何番目スタートか、プレイヤー名、ダブルのルールを決めて「開始」
2. 自分の手札を、色 × 競り方式の表からクリックで選ぶ（✕ で取り消せます）
3. あとは画面上部に「次に何を入れるか」が常に出るので、それに答えるだけ
4. 自分が決める場面では、右側に AI の推奨と候補ごとの勝率が出ます。
   カードの表では推奨が金色の枠で光ります

いつでも「1つ戻す」で入力をやり直せます。「リセット」で最初からやり直せます。

### コマンドから使う場合

ターミナル版と、起動オプションの指定はこちら。

```bash
cd ~/projects/art/"Modern Art AI"   # WSL / Linux の場合
./modernart.sh                      # ブラウザ版
./modernart.sh --cli                # ターミナル版
```

Windows のコマンドプロンプトからは、`モダンアートAI.bat` に引数をそのまま渡せます。

```
モダンアートAI.bat --time 20
```

### オプション

どちらの版でも共通。

| | |
|---|---|
| `--time 20` | 1手あたりの思考時間（秒、既定 12） |
| `-j 8` | 並列数（既定は CPU コア数、最大8） |
| `--rollout greedy` | ロールアウトを軽い方策にする。1秒の持ち時間では有意差なし |
| `--no-affinity` | 「相手が推している色」の推定を切る |
| `--port 8765` | ブラウザ版のポート |
| `--load game.pkl` | ターミナル版のみ。保存した途中経過から再開 |

金額はどちらも**千円単位**（`24` = 24,000円）。

### ターミナル版の入力の書き方

- カード: 色1文字 + 方式1文字。`黄公` `緑倍` `桃差` `青入` `肌声`
  - 色 = 黄 緑 桃 青 肌（`y g p b s` でも可）
  - 方式 = 公(公開競り) 声(一声) 入(入札) 差(差し値) 倍(ダブル)
  - `YO` `gd` のようなローマ字、`ピンク差し値` のような長い表記も通る
- 落札は `2 24` のように「落札者 金額」でまとめて入力
- どの入力欄でも `undo` `state` `unseen` `hand` `save <file>` `load <file>` `?` が打てる

### 考え方

**競りの値付け** — lot の期待価値を W、相手の得を自分の損として見る重みを
γ（1人あたり g = γ/(n-1)）とすると、払ってよい上限は

```
競売人でない: q_max = (W + g·W_rival) / (1 + g)
競売人       : q_max = (W + g·W_rival) / (2 + g)
```

競売人のときに上限がおよそ半分になるのは、自分で落札すると代金が銀行に消えて
売上が入らないため。ここに方式ごとの掛け目を掛けたものを留保価格とする。

**画家の価値** — ラウンドはどれか1色が5枚出た時点で終わる。よって「いま何枚
出ているか」と「まだ手札に何枚残っているか」が決まれば順位の分布はほぼ決まる。
これを短いモンテカルロで推定してキャッシュする（`valuation.py`）。

**探索** — 観測と矛盾しない相手の手札をサンプルし（`beliefs.py`）、その完全情報の
局面で候補手をそれぞれ試し、以降はヒューリスティック方策で終局まで進めて採点する。
同じサンプルで全候補を試すので候補どうしの比較の分散が小さい。生き残っている
候補には常に同じ回数を割り当て、勝ち目がないと言い切れる候補だけ打ち切る。

**候補どうしの比較には「同一サンプル上での差」を使う。** それぞれの平均勝率を
比べると、対応のない標準誤差（±5ポイント規模）が閾値になってしまい、実際には
有意な差でも埋もれる。同じ配牌の上で両方を試しているので、差の分散はずっと小さい。
ここを間違えていた間、探索は評価関数と互角のままだった（25.0% → 43.8%）。

**差が誤差の範囲なら評価関数の手を採る。** 9択の平均値をそのまま比べると必ず
どれかが上振れて1位になる（勝者の呪い）。探索は有意差があるときだけ上書きする。
このとき表の1位と推奨がずれるので、画面にその旨を出している。

## 実装しているルール

- デッキ70枚。黄12 / 緑13 / 桃14 / 青15 / 肌16。同数時の優先順位は黄 > 緑 > 桃 > 青 > 肌
- 配札 3人 10/6/6/0、4人 9/4/4/0、5人 8/3/3/0。**未使用の手札はラウンドをまたいで持ち越す**
- 所持金は各自 100（=100,000円）
- 落札者は競売人に支払う。**競売人自身が落札した場合は銀行へ**（お金が場から消える）
- 一声は競売人が最後に声を出す。入札の同額は競売人が最優先、以降 時計回り
- 差し値で全員が断ったら、競売人が自分の提示額を銀行に払って引き取る
- ダブルの2枚目は**ダブル以外**のカード。出せない/出さない場合は左隣から順に権利が移り、
  出した人が競売人になって売上を全額受け取る。誰も出さなければ1枚目を出した人が無料で取得
  - **2枚目の色**は卓によって扱いが違うので、開始画面のチェックで切り替える。
    「別の色も可」なら、落札者は2色の絵を1枚ずつ得て、両方の色の出品数が増える
- ある画家の5枚目が出た瞬間にラウンド終了。**その5枚目は競売されず誰の物にもならないが、枚数には数える**
- 決算は上位3画家に +30 / +20 / +10 を**累積**加算。4位5位の絵は0円
- 次ラウンドの開始プレイヤーは、前ラウンドで最後に出品した人の左隣

裁定が分かれる点は次のように決めた（変更したい場合は該当箇所を直せばよい）。

- ダブルの2枚目に**ダブルカードは出せない**（`state.legal_seconds`）
- 2枚目の色の制限は `GameState.double_any_artist` で切り替える。公開されている
  ルール説明はどれも「同じ画家（＝同じ色）」だが、別の色を許す卓もあるため選べるようにした
- 差し値で全員が断ったら**競売人が自腹**（`rules.resolve_auction`）
- ダブルの2枚目を他人が出してラウンドが終わった場合、「最後に出品した人」は
  **手番だったプレイヤー**として扱う（`state.last_turn_player`）。次ラウンドの
  開始プレイヤーがこの1つ隣に変わるだけの稀なケース
- カードの内訳は `cards.py` の `DECK_TABLE` 1箇所にまとまっている

## 開発

```bash
python3 -m unittest discover -s tests -t . -q          # テスト
python3 -m modernart.arena --agents heuristic,heuristic,greedy,random -n 600
python3 -m modernart.tune --iters 12 --pop 14 --games 540   # パラメータを調整
python3 -m modernart.tune --double-any-color               # 別色ダブルのルール用
```

エージェント名は `random` / `greedy` / `heuristic` / `pimc`。`:` で細かく指定できる。

- `heuristic:default` … 調整前のパラメータ
- `heuristic:tuned` … `params/tuned.json`（既定）
- `heuristic:path/to.json` … 任意のパラメータ
- `pimc:greedy:0.3` … ロールアウト方策と1手あたりの秒数

### 実測した強さ

自己対戦の結果（`params/tuned.json` は4人卓で調整したもの）。

| 対戦 | 調整後 | 調整前 | 期待勝率 |
|---|---|---|---|
| 4人 × 720局 | **88.3%** ±2.3 | 4.6 / 4.3 / 2.8% | 25% |
| 3人 × 600局 | **86.2%** ±2.8 | 7.3 / 6.5% | 33.3% |
| 5人 × 600局 | **95.3%** ±1.7 | 1.7 / 1.3 / 1.2 / 0.5% | 20% |

4人卓だけで調整したパラメータが3人・5人でもそのまま効いている。

探索の効果（全員 調整済みパラメータ、1手1秒、4人 × 96局）:

| | 勝率 |
|---|---|
| `pimc:heuristic:1.0` | **43.8%** ±9.9 |
| `heuristic` ×3 | 24.0 / 19.8 / 12.5% |

序列（4人 × 720局）: `heuristic` 37.8% / 37.0% > `greedy` 25.1% > `random` 0.0%。

### 自己対戦が教えてくれたこと

調整がパラメータをどう動かしたかは、そのまま戦術の指針になる。

- **競りは期待価値を超えて張る**（掛け目 0.78 → 1.35）。公開競りは「2位の額+1」で
  決まるので、留保価格を上げても普段はそこまで払わずに済み、競り勝つ回数だけ増える。
- **リスク回避は不要**（`risk` 0.30 → −0.22）。
- **手札の温存価値はほぼゼロ**（`future_weight` 0.30 → 0.16、途中の世代では負）。
  持っていても売上にならない。

### 測定を歪めないための工夫

- **`arena` は席順の全順列を巡回させる。** 単に席を回すだけだと「誰の左隣に座るか」が
  固定されてしまい、*同じエージェント同士でも* 勝率に8ポイント以上の差が出る。
  モダンアートは隣人が誰かで有利不利が変わるので、ここを揃えないと比較にならない。
- **`tune` は歴代チャンピオンのプールを相手にする。** 直前のチャンピオン1体だけを
  相手にすると「その相手にだけ効く小細工」に収束してしまう。
- **交代は独立した再測定で有意差が出たときだけ。** 世代内の最良は定義上「上振れた候補」
  なので、そのまま採用すると毎回ノイズを掴む。
- **`pimc` の探索は生き残った候補に同じ回数を割り当てる。** 割り当てが不揃いだと、
  サンプルの少ない候補がまぐれで1位になる。候補の優劣は「同じ配牌の上で測った差」で
  判定する。平均どうしを比べると誤差の見積りが大きくなりすぎ、探索が何も上書きできない。
- **`tune` は動かない基準（出発点のパラメータ）にも勝つことを要求する。** 歴代プール
  だけで判定すると、*プールごと弱い方へ流れても*「プールには勝っている」ので改善に
  見えてしまう。実際にこれで強さ指数 1.155 と報告された値が、実測では勝率 2% だった。
- **`tune` は強くなったときだけファイルを書き出す。** 改善が無ければ既存の値を守る
  （`--force` で上書きできるが通常は使わない）。
- **パラメータは 3人・4人・5人を混ぜて調整する。** 4人だけで回すと4人にしか効かない。
